\begin{frame}{Experiment Variables}
  \begin{columns}[T]
    \column{0.48\textwidth}
    \textbf{Controlled factors}
    \begin{itemize}
      \item Number of input views
      \item Scene-level train / validation / test split
      \item Fixed threshold on final test
    \end{itemize}

    \column{0.48\textwidth}
    \textbf{Observed outcomes}
    \begin{itemize}
      \item Reconstruction accuracy
      \item Completeness and consistency
      \item Runtime per scene

    \end{itemize}
  \end{columns}

\begin{frame}{Training Strategy}
  \footnotesize
  \begin{enumerate}
    \item First build a supervised label cache with per-view visibility,
    occlusion, floating/wrong-depth, and match labels.
    \item Mine occlusion-heavy, low-overlap, and hard-negative subsets before
    training the learned heads.
    \item Freeze MV-DUSt3R+ and train small reliability / match heads on
    generated GT labels; Run 21 trains the first OARH v2 multitask head from
    Run 20 labels without direct target-label leakage features.
    \item Run 22 applies the learned OARH v2 head to reconstruction candidates;
    the validation gate keeps fixed confidence because proxy labels do not
    transfer to geometry F-score.
    \item Run 23 retrains reliability on actual MV-DUSt3R candidate points and
    nearly recovers fixed confidence only when keeping almost all candidates.
    \item Run 24 trains RSDH v2 from image-only match features and passes its
    proxy gate for repeated-structure / wrong-match ambiguity.
    \item Run 25 integrates the Run 24 RSDH v2 head into reconstruction
    candidate scoring and keeps it only if validation geometry F-score wins.
    \item Run 26 adds all-candidate and confidence top-k baselines with exact
    top-k masks to verify whether RSDH gives a real ranking gain.
    \item If validation improves, unfreeze only the confidence head and last
    decoder blocks for light fine-tuning.
    \item Keep final test clean: no threshold tuning, no checkpoint selection
    on test scenes.
  \end{enumerate}
\end{frame}
